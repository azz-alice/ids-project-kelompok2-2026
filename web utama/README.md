# Web Utama

Dashboard desktop-first dengan fokus utama pada tabel Live Traffic dan grafik garis real-time per detik, disertai navigasi drawer yang tertutup saat pertama dibuka. Menyediakan halaman Live Traffic, Pengunjung, Detection, Alerts, Logs, Investigation, Traffic Analysis, Baseline, Threat Intelligence, System Health, dan System Control.

File utama: `index.html`, `assets/css/styles.css`, `assets/js/api.js`, `assets/js/format.js`, `assets/js/grafik.js`, `assets/js/tabel_traffic.js`, `assets/js/halaman.js`, dan `assets/js/app.js`.

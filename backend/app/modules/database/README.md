# Database

Menyediakan SQLite schema, koneksi, query, transaksi, retensi data, serta helper waktu dan JSON. Tabel utama meliputi sessions, activities, application_events, packet_events, traffic_windows, detections, alerts, incidents, system_logs, threat_intel_cache, dashboard_events, component_status, dan baseline_state.

Database dibuat otomatis pada startup. File database runtime tidak disimpan di repository.

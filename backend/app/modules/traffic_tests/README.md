# Traffic Generator

Menyediakan profil request lokal dengan batas jumlah, interval, ukuran payload, dan durasi. Browser Web Pengunjung mengirim request aktual ke Guest API berdasarkan profil tersebut.

Skenario: normal, volume spike, variasi ukuran payload, dan peningkatan frekuensi request. Generator hanya menargetkan server lokal proyek dan tidak boleh menghasilkan traffic tanpa batas.

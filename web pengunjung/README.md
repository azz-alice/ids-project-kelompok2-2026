# Web Pengunjung

Antarmuka mobile-first dalam satu viewport HP untuk menampilkan ticket dan timer sesi dari server serta mengirim tiga skenario traffic tidak normal (kenaikan volume traffic, perbedaan ukuran data, dan peningkatan frekuensi request) dengan cooldown 30 detik per pengunjung.

File utama: `index.html`, `assets/css/styles.css`, `assets/js/api.js`, dan `assets/js/app.js`.
